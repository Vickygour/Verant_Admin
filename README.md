# VÉRANT Admin Panel (React + Tailwind + Vite)

1. `npm install`
2. `.env` me `VITE_API_URL` apne backend ka URL do (default `http://localhost:5000/api`)
3. `npm run dev` -> http://localhost:5173
4. Login sirf **role: admin** wale user se hoga. User ko admin banane ke liye MongoDB me `role: "admin"` set karo.

Backend `.env` me `CLIENT_URL` me admin ka URL add karna mat bhoolna (agar CORS restrict karo).
